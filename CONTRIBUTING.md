# Contribuir a BRENO

Gracias por querer mejorar BRENO. Puedes abrir un issue para reportar un problema o proponer una idea, o enviar un pull request.

## Preparar el entorno

1. Instala Node.js 22 y pnpm 11.
2. Ejecuta `pnpm install`.
3. Ejecuta `pnpm dev` para iniciar el entorno local.
4. Para trabajar con autenticación, copia `.env.example` a `.env.local` y usa un proyecto Supabase propio.

## Pull requests

- Explica qué problema resuelve el cambio y qué comportamiento afecta.
- Mantén las credenciales, tokens y datos personales fuera del repositorio.
- Actualiza la documentación de configuración cuando añadas variables o servicios.
- Ejecuta `pnpm build` antes de solicitar revisión.

El proyecto está publicado bajo la licencia MIT. Al enviar una contribución, aceptas que se distribuya bajo esa misma licencia.
